# 需求流程

需求流程以个人工作站和独立事项为基础，组织机会发现、官方来源检索、条件自查、导师联系判断、计划确认、个人竞赛任务、材料写作与归档。十三项用例、十七项功能及三十个待执行场景采用一致编号。

官方要求由Agent按需检索、读取原文与附件、提取并程序检查；个人自查使用按现有信息符合、按现有信息不符合、待补充信息、待用户核对。上传资料保留本人当前事项范围，个人档案由本人选择复用，用户对提供材料作出担保。

用户确认与机器自动检查分别记录。L3限定高影响产品内操作；对外联系、报名和提交由用户自行办理。系统衔接稿与图源描述三层信息、独立官方引用、确认事务及来源版本序，供系统、原型与数据库设计采用。

确认事务以同一来源锁及本人工作站守卫防止并发版本变化。个人事实和证明分别留版，事项只引用用户明确选用的版本，删除事项保留本人资料库。
