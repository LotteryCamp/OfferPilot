# 需求流程部分

我依据新版产品策划稿修订需求流程，覆盖推免与竞赛两类个人工作区，保留原编号并形成十三项业务用例、十七项功能和三十个流程验收场景。补充了机会发现、投入取舍、个人事项授权、校内实际审核节点、竞赛阶段、事实档案以及提交前复核与结项归档。

页面统一使用符合已核实条件、尚未符合、待补充信息、需人工核实四种对照结果。材料既可从零散事实起草，也可基于原稿局部修改，逐项审阅后导出新的DOCX。来源自动对比和提醒能力按P1区分，避免扩大首版承诺。

领域条款引用杜玉鹤维护的规则编号。赛项具体规则在名称和官方资料确定后配置，不能假设通用人数与赛道。验收场景当前待执行，真实讨论、核验和测试结果发生后另留记录。
