# Beta 推免工作区关键页面状态

附 [Figma 状态板](https://www.figma.com/design/feczCbKUHrybftac7eB7qW/OfferPilot?node-id=27-472)。具体前端恢复行为沿用 [核心流程约定](core-flow.md)，下表用于对照 11 月 28 日联调。

| 页面 | 触发条件 | 界面反馈 | 主操作与恢复 |
| --- | --- | --- | --- |
| 登录 | 登录页初始／正在提交 | 显示账号和密码，提交中给出进度并锁定重复提交 | 登录 |
| 登录 | 凭据校验失败／会话失效 | 表单附近说明失败原因；重新登录页标出会话失效 | 重新提交或登录后继续 |
| 工作台／概览 | 正在读取／读取失败／实际无事项 | 标题和导航可见；错误与空列表分别显示。读取成功且为空时显示「暂无事项」 | 失败时重试读取；空列表时新建工作区 |
| 来源 | 空列表／读取中／读取失败 | 已读内容可继续展示；首载显示加载提示。失败展示原因，保留可用快照 | 导入通知／等待／重试读取 |
| 来源 | 正常读取／快照更新 | 显示当前快照及获取时间、发布机构和原文；历史快照明确标识，核对所选版本对应的要求与引用 | 查看原文、快照或当前缺口 |
| 自查 | 排名缺失、范围未知或证据不足 | 标出受影响的要求与出处；排名缺失显示「待补充信息」，证据不足显示「待核对」 | 补充本人排名或查看对应证据 |
| 排名 | 输入不合法或本人未确认 | 错误紧贴字段，继续显示已输入内容；计算预览标明用途 | 修正排名／总人数并确认 |
| 排名 | 保存中／保存失败 | 显示保存进度并阻止重复提交；失败说明原因并保留输入 | 等待或重试保存 |
| 自查 | 排名已保存，正在重新自查 | 分开显示排名保存结果与自查进度，标示所用来源 | 等待读回 |
| 自查 | 公开资料的模型传输同意缺失或已撤回 | 保留已保存排名，提示同意范围和自查尚未发起。此时调用 Agent 运行入口会返回 `422 model_transfer_consent_required` | 可先保存排名。授予公开资料的模型传输同意后，再选「仅重新自查」 |
| 自查 | 排名已保存但自查失败、暂不可用或结果待核对 | 保留已保存排名，说明当前状态，提示核对已保存分析结果 | 先读回已保存结果。确认可重新运行且模型传输同意有效后，选择「仅重新自查」 |
| 自查 | 重跑成功 | 显示各项自查、当前出处与剩余缺口；证据不足继续待核对 | 条件允许时生成候选计划，已存在时审阅 |
| 候选 | 暂无／生成中／生成失败或读取失败 | 区分空列表、进度与失败。已保存且成功读取后才显示审阅入口 | 生成、等待或重试读取 |
| 候选 | 生成请求响应丢失，尚未取得运行 ID | 显示「结果待核对」，先刷新已保存的来源和候选。取得运行 ID 后可查询运行 | 接口恢复时向同一事项提交原 `operation_id`。同键并发请求由后端串行处理，复用待处理或已完成的运行及其结果。原运行已失败、已取消或已中断时，同键重试会创建新运行 |
| 候选 | 待确认 | 展示版本、适用范围、候选条目、期限、依赖和来源。核对复选框后启用当前可用的决定动作 | 确认采用并创建任务；拒绝此候选计划 |
| 候选 | 提交中／结果待核对 | 提交中锁定两项决定；结果待核对时说明可恢复动作并锁定相反决定 | 重新读取，或沿用同一次操作标识重试原决定 |
| 候选 | 依据变化、存在关键阻断或已过期 | 说明具体原因和受影响条目；过期时标记版本并提供返回来源路径 | 修正缺口、重新读取或重新生成后审阅 |
| 候选 | 已确认 | 显示决定时间及读回的创建结果；任务读取失败时保留已确认状态 | 查看任务，或重试读取任务 |
| 候选 | 已拒绝 | 显示决定时间与「本计划未创建任务」，保留版本供回看 | 返回工作区 |
| 任务 | 加载／读取失败／空列表 | 区分加载、失败和读取成功后的「暂无正式任务」；始终保留事项上下文 | 等待／重试加载／查看候选计划 |
| 任务 | 正常读回 | 显示正式状态、前置依赖、完成证据、官方期限、建议准备日。原文只有日期时保留日期精度 | 查看任务依据 |
| 材料草拟 | 无草稿／待补事实／已有草稿 | 提示需要核对的事实，草稿展示对应引用，空状态提供下一步 | 草拟、补充事实或审阅草稿 |
