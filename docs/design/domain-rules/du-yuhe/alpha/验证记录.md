## 复现与交接

在解压目录执行本包的离线校验和来源核对。

```text
python -B verify.py
python -B check_sources.py
```

复现上表时，准备含指定提交的本地 OfferPilot 检出目录，使用该项目的锁定依赖。从本包目录运行下列命令，将占位路径换为检出目录。

```text
uv run --project "<OfferPilot检出目录>/backend" --locked --no-dev python -B compare_agent.py "<OfferPilot检出目录>"
```

在 `fc57b26` 上最后一条命令的退出码为1，对应表中4项差异。比较其他版本时应一并记录提交号和实际输出。团队端到端验收和演示当天的来源可用性仍待核验。
