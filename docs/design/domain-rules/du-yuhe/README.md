# OfferPilot 领域规则依据

当前版本1.4，以新产品策划稿中的个人事项Agent定位为基线，整理43条规则和60个待执行的验收场景。

内容覆盖个人工作区、官方公开来源与两类私有信息的隔离、Agent自动检索和检查、个人自查四态、写作与DOCX导出、个人归档及L0至L3产品内授权。资料处理不以人工维护或发布公共规则库为前提，不含多人共享、他人任务或第三方审核能力。

Markdown为源稿，Word可编辑，PDF供阅读；配套规则、来源、对齐与验收清单，含判定样例、竞赛配置、系统衔接表及图源。规则与验收编号可供系统和数据库设计引用，业务环节按当前个人流程对应。

竞赛名称与官方条款待补充，个人条件自查保持未启用。推免政策仅是历史局部样例。所有验收场景均待执行，不代表已经实现、自动检查成功或测试通过。

个人工作站与用户一一对应，多个事项分别管理。官方缓存只含机器独立采集的公开证据；上传线索、检索记录与个人分析保持本人范围。个人材料由用户担保，事实值与证明文件分别留存版本。
