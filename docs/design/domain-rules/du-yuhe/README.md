# OfferPilot 领域规则依据

本文整理三十八条规则、三个推免官方实例和四十八个待执行的规则验收场景，区分院校条款、产品需求及设计细化。

Markdown为源稿，Word为可编辑版，PDF用于阅读。配套资料包括规则清单、资料索引、验收场景、判定样例、竞赛配置、策划要求对齐表、依据关联图及博客素材。

流程引用采用HHY-UC01至HHY-UC13，供需求、系统及数据库设计关联。规则与验收编号保持一致，便于追溯对应关系。

赛项具体名称与官方章程待补充，空字段不得作为已核实政策；目前只启用探索、缺口和拒绝用例，取得适用规则并完成独立复核后才能执行确定判断。推免实例为历史局部条款，不表示完整资格认定。

当前版本1.2。所有验收场景均为设计依据，实际运行结果另行填写。
