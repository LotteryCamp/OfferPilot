# 领域规则依据

领域规则按个人事项Agent定位组织，覆盖推免与一个竞赛试点，共43条规则和60个待执行场景。Agent按需查找官方入口、读取附件、提取字段并自动检查；规则保留原文、范围、获取时间和版本，不将机器处理或个人确认称为官方认定。

官方公开来源、本人当前事项线索及个人档案分层保存。跨用户读取被拒绝，其他事项线索不自动进入当前上下文，个人档案由本人选择字段与版本复用；上传截图和派生内容保持原有来源属性，外部搜索不带私有字段。

个人自查统一使用按现有信息符合、按现有信息不符合、待补充信息、待用户核对。校内进度及对外办理结果由用户手动记录；L3只限高影响产品内操作，不包含联系、报名、公开发布或材料提交。人工独立标注仅用于开发评测，不构成日常资料审核岗位。

配套策划要求对齐表、竞赛配置、来源索引和判定样例。具体赛项待补充，测试结果在执行后记录。

个人工作站组织多个独立事项；官方公开原文可只读缓存，个人检索与分析仍按本人事项隔离。用户对提供材料的真实性、完整性和可用性作出担保，来源当前快照和确认版本分别检查。
