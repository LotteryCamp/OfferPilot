## 单一竞赛事项模板

事项类型为 `competition`，年度为 2026，目标为参加本校校内选拔。

| 编号 | 类别与位置 | 预期及边界 |
| --- | --- | --- |
| CO-01 | 官方对象，三及四（三） | 本校全日制在校本科生或研究生个人参赛。学生本人确认学籍与在校状态 |
| CO-02 | 官方报名，四（一）和六 | 线上注册、报名与自主学习安排截至 2026-09-18。本人填写并核对注册信息，再点校赛报名。只注册的状态保留报名缺口。正文给出日期精度，具体关停时刻及平台字段待核对。正文未列出独立作品或材料上传环节 |
| CO-03 | 官方阶段，四（三） | 平台个人答题用于校赛选拔。得分、用时排名和省赛名单由组织方确认 |
| CO-04 | 官方时段和建议，六温馨提示 | 北京时间 9 月 19 日 06:00 开放，到 9 月 20 日 24:00 关停，答题计时 120 分钟。建议在 22:00 前进入。答题按校赛阶段单独显示，报名要求保持日期精度 |
| CO-05 | 省级目录附件，附件 1 | 人工依据 PDF 第 7 页第 59 项核对赛事出处。依赖该扫描内容的机器检查保持待核对 |

最小候选计划包含注册账号和本人完成报名两项，报名依赖注册。前一项保留建议准备日，后一项的官方截止只填日期。保存候选时事项内正式任务为零，确认后生成两项，可按任务出处回看通知。拒绝、报名日期已过两种分支均应保留零项正式任务。

## 复现

从 `backend` 目录运行。API 用例需要按[本地安装与配置](../../../../getting-started.md)准备独立 PostgreSQL 测试库，应用迁移、参考种子和测试角色权限，并配置两个测试连接串。

```powershell
uv run --locked pytest tests/test_beta_domain.py -q -k 'not live_source'
```

线上回看使用同一读取器。公告调整时，重新对照原文位置和适用范围后再更新快照。

```powershell
$env:OFFERPILOT_BETA_DOMAIN_LIVE = '1'
uv run --locked pytest tests/test_beta_domain.py -q -k live_source
Remove-Item Env:OFFERPILOT_BETA_DOMAIN_LIVE
```

推免接收、竞赛的正常确认分别用固定时钟 2026-09-22 07:30 和 2026-09-17 10:00（北京时间）回放。候选输入来自人工核对的来源条款，验收记录适用于后端业务 API。排名组合条件由样例判定表覆盖，替代成绩、材料、时间及来源缺口使用现有 Agent 规则校验器。

## 验证记录

11 月 26 日以 `main @ ee0a933` 为基线，在 Python 3.13.18 与独立 PostgreSQL 16.16 上应用 18 个迁移和参考种子，通过 55 项 #74 用例。其中 47 项为规则、排名及引文检查，3 项为官方正文在线回看，5 项为 API 冒烟。[测试基线](https://github.com/LotteryCamp/OfferPilot/commit/ee0a9337ecff573dfd656f42fac091ac412ecb41)

推免与竞赛两个确认用例各落库两条任务，重复确认复用任务，另一同类事项仍为空。竞赛拒绝与过期确认各保留零条任务。来源年度不符时要求写入返回 `422 scope_year_mismatch`。竞赛截止保留日期字段，时刻字段为空。

11 月 27 日的 P0-04 真实模型联调使用同一份接收通知。候选确认识别到 GR-07 的北京时间 2026-09-22 08:00 截止，过期确认返回 `official_deadline_passed`，事项正式任务为零。[过期场景联调证据](https://github.com/LotteryCamp/OfferPilot/issues/73#issuecomment-7218362003)

P0-04 可用推免接收样例对照条件、日期、引用与候选依赖，并独立复核未定的复试日期和材料缺口。竞赛仅覆盖该年度福州大学校内选拔。竞赛前端与发布范围按 Beta 验收决策确认。[Beta 验收追踪](../../../../../beta-release-tracking.md)
