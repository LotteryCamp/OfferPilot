## 一、冲刺计划

本轮冲刺计划见：[OfferPilot Alpha 冲刺计划（模块视图）](./OfferPilot_Alpha冲刺计划_模块视图.md)。计划周期为 2026 年 11 月 16—29 日，目标是把个人事项、公开来源、Agent 要求整理、候选计划和用户确认串成可运行的演示闭环。

冲刺主线为：

```text
创建个人事项 → 读取公开来源 → 提取要求并保留出处 → 生成候选计划 → 用户确认 → 写入个人任务
```

计划分为六个模块：产品与原型、Agent 与模型调用、领域规则与公开来源、前端工作区、后端业务与数据、验收与测试。团队每天通过 Issue、PR 和异步更新同步进展；11 月 17 日安排一次约十分钟的站立会议，技术细节在会后通过 Issue 和 PR 处理。

## 二、阶段进展与项目思考

### 2.1 当前已确认的进展

截至 11 月 18 日，仓库已有产品方案、需求流程、领域规则、Agent 集成设计、系统设计、数据库设计、原型材料和 Page 2 审查记录。Alpha 计划将这些设计材料转为可运行的核心流程，并明确每个模块的验收证据。

我的负责模块为“来源与引用处理”。PR [#37 feat(source): read public HTML sources](https://github.com/LotteryCamp/OfferPilot/pull/37) 已在 `feat/public-source-reader` 分支提交实现，最新提交为 [`893bb6c`](https://github.com/LotteryCamp/OfferPilot/commit/893bb6c669ee5c3e9f74e01a89e75c6cabcdda1f)。目前已经完成以下内容：

- 读取公开 HTTP/HTTPS HTML 页面，保留最终 URL、发布主体、适用年度、获取时间和内容摘要。
- 为来源和内容快照生成稳定标识，支持页面内容变化后的版本登记。
- 输出段落、列表项和表格行定位，使 Agent 和页面能够回到原文位置。
- 对 DNS、连接、TLS、响应头和正文读取设置总截止时间，并限制响应大小。
- 拒绝环回、私有、链路本地和保留地址，避免把读取器变成内网探测入口。
- 将来源登记、事项关联和证据片段保存到独立 SQLite 适配器，并明确生产 PostgreSQL 需要后端另行接入。
- 使用福州大学公开通知快照和真实网页进行验证；当前本地测试为 93 项，Ruff 检查、构建和在线读取验证均已通过。

上述代码仍处于 PR 审阅流程，不能写成已经合并到主分支的功能。其余成员的实际进度应以 11 月 21 日前的 PR、Issue、运行截图和测试记录为准。

### 2.2 项目亮点

1. **来源可回溯。**要求、引用和快照之间保留稳定关系，页面能显示出处和定位信息。
2. **Agent 有边界。**候选计划需要用户确认后才写入正式任务，来源读取失败时返回明确错误，不生成伪成功结果。
3. **设计与实现有对应关系。**领域规则、数据模型、页面状态和验收条款都能映射到后续代码或测试任务。
4. **安全检查进入基础模块。**公开来源读取对 URL、DNS、连接超时、响应大小和 HTML 解析进行限制，并避免把用户私有事实混入公开引用。
