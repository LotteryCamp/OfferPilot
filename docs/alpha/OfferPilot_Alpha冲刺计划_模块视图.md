## Alpha目标

14天优先做成一个可本地运行、可演示的推免事项核心闭环：

**创建个人事项 → 读取公开来源 → Agent 提取要求并展示出处/范围/缺口 → 生成候选计划 → 用户确认后写入个人任务 → 查看任务状态。**

竞赛本轮只整理规则和验收样例，不承诺完整竞赛流程。材料自动改写、真实 DOCX 导出、所有事项模板、完整后台和定期巡检不纳入本次交付承诺。团队按每天可检查的产物推进，不以静态原型代替可运行功能。
