## Highlights

- 🐍 Python 驱动的网络服务和 Agent 框架，提供高效性能
- 🖥️ 清晰分层的用户界面，提升工作效率
- 🛡️ 隐私优先，保护个人信息安全
- 🌈 MIT 开源，可自托管

## Security

本项目处于积极开发状态。我们主要为最新版本提供支持，因此我们推荐用户保持软件更新。

如你发现本项目存在安全问题，请通过 [GitHub's Security Advisory](https://github.com/LotteryCamp/OfferPilot/security/advisories/new) 报告问题，我们将努力处理你的报告。
